# NUCLEO-F446ZE 2륜 밸런싱 로봇

이 프로젝트는 다음 배선에 맞춰 생성되어 있다.

| 기능 | TB6612FNG | NUCLEO-F446ZE |
|---|---|---|
| 대기 해제 | STBY | A0 / PA3 |
| 왼쪽 PWM | PWMA | D10 / PD14 / TIM4_CH3 |
| 왼쪽 방향 | AIN1, AIN2 | D2 / PF15, D4 / PF14 |
| 오른쪽 PWM | PWMB | D9 / PD15 / TIM4_CH4 |
| 오른쪽 방향 | BIN1, BIN2 | D7 / PF13, D8 / PF12 |
| MPU6050 SCL | SCL | D15 / PB8 / I2C1_SCL |
| MPU6050 SDA | SDA | D14 / PB9 / I2C1_SDA |

MPU6050 전원은 NUCLEO의 3V3와 GND에 연결하고 AD0는 GND에 연결한다.
TB6612FNG의 VM에는 외부 6V, VCC에는 3V3를 공급한다. 외부 전원의
마이너스, TB6612 GND, NUCLEO GND는 반드시 공통이어야 한다.

## MPU6050 장착 방향

이 펌웨어는 아래 방향을 기준으로 각도를 계산한다.

- 센서 기판을 세워진 폼보드 면과 평행하게 고정한다.
- MPU6050의 X축이 차체 위쪽을 가리키게 한다.
- MPU6050의 Y축이 좌우 바퀴 축과 평행하게 한다.
- 차체가 똑바로 서면 출력의 `ANG`가 0에 가까워야 한다.

`ANG`는 0.01도 단위다. 예를 들어 `ANG=523`은 5.23도다. 차체를
앞으로 기울였을 때 `ANG`가 음수가 되면 터미널에서 `SSIGN -1`을
입력한다. 똑바로 세웠을 때 약 180도가 나온다면 센서 X축이 아래를
향한 것이므로 센서를 180도 돌려 다시 고정해야 한다.

## 프로그램 열기와 다운로드

1. STM32CubeIDE를 실행한다.
2. `File > Import > Existing Projects into Workspace`를 선택한다.
3. `D:\stm_project\BalanceBot_F446ZE\STM32CubeIDE`를 선택한다.
4. NUCLEO의 ST-LINK USB를 PC에 연결한다.
5. 프로젝트를 빌드한 뒤 `Run`을 눌러 다운로드한다.

이미 빌드된 이미지는 다음 위치에 있다.

- `STM32CubeIDE\Debug\BalanceBot_F446ZE.elf`
- `STM32CubeIDE\Debug\BalanceBot_F446ZE.hex`
- `STM32CubeIDE\Debug\BalanceBot_F446ZE.bin`

## 최초 시험 순서

처음에는 반드시 차체를 들거나 안전줄을 사용해 바퀴가 바닥에 닿지
않게 한다.

1. 모터 배터리를 연결하고 NUCLEO를 리셋한다.
2. 약 2초 동안 자이로를 보정하므로 차체와 센서를 움직이지 않는다.
3. ST-LINK 가상 COM 포트를 `115200, 8-N-1`로 연다.
4. `STATUS`를 입력하고, 차체를 앞뒤로 기울여 `ANG` 방향을 확인한다.
5. `TEST L 120`, `TEST R 120`, `TEST BOTH 120`을 차례로 실행한다.
   각 명령은 0.4초 뒤 자동 정지한다.
6. 양쪽의 양수 시험이 모두 차체의 전진 방향이어야 한다.
7. 한쪽이 반대라면 해당 방향을 `LSIGN -1` 또는 `RSIGN 1`로 바꾼다.
8. 차체를 수직에서 약 ±8도 이내로 잡고 B1 버튼을 누르거나 `ARM`을
   입력한다.
9. 즉시 정지하려면 B1을 다시 누르거나 `STOP`을 입력한다.

초기 방향값은 `LSIGN=1`, `RSIGN=-1`이다. 모터 선 연결 방향에 따라
바꿔야 할 수 있다.

## LED 상태

| LED | 상태 |
|---|---|
| 파란색 | READY, 모터 정지 |
| 초록색 | ARMED, 평형 제어 동작 |
| 빨간색 | FALLEN 또는 MPU6050 통신 오류 |

기울기가 35도를 넘거나 MPU6050 읽기가 연속으로 실패하면 STBY를
LOW로 내리고 모터를 정지한다.

## 시리얼 명령

| 명령 | 설명 |
|---|---|
| `ARM` | 수직 ±8도 이내에서 제어 시작 |
| `STOP` | 즉시 모터 정지 |
| `STATUS` | 각도, 자이로, 출력 및 설정 표시 |
| `KP 30` | 비례 게인 변경 |
| `KD 1.3` | 미분 게인 변경 |
| `KI 0` | 적분 게인 변경 |
| `TARGET -0.3` | 수직 기준각 보정 |
| `DEAD 70` | TT 모터 최소 구동 PWM |
| `MAXPWM 600` | 최대 PWM 제한 |
| `SSIGN -1` | 센서 각도 방향 반전 |
| `LSIGN -1` | 왼쪽 모터 방향 반전 |
| `RSIGN 1` | 오른쪽 모터 방향 반전 |
| `TEST L 120` | 왼쪽 모터 0.4초 시험 |
| `TEST R 120` | 오른쪽 모터 0.4초 시험 |
| `TEST BOTH 120` | 양쪽 모터 0.4초 시험 |

명령으로 바꾼 값은 리셋하면 초기값으로 돌아간다. 영구 변경하려면
`balance_bot.c`의 초기 게인과 방향값을 수정한다.

## 첫 PID 조정

초기값은 `KP=28`, `KI=0`, `KD=1.10`, `DEAD=70`, `MAXPWM=600`이다.
이 값은 안전한 시작점일 뿐이며 차체 무게, 바퀴, 모터와 배터리에 따라
반드시 달라진다.

- 힘이 부족해 그대로 넘어지면 `KP`를 2씩 높인다.
- 빠르게 앞뒤로 떨리면 `KD`를 0.1~0.2씩 높이거나 `KP`를 2씩 낮춘다.
- 모터가 작은 출력에 전혀 반응하지 않으면 `DEAD`를 10씩 높인다.
- 기본 평형이 잡히기 전에는 `KI`를 0으로 유지한다.
- 평형은 잡히지만 한 방향으로 천천히 이동하면 `TARGET`을 0.1도씩
  바꿔 본다.

엔코더가 없으므로 각도 평형은 가능하지만 제자리 위치를 정확히
유지하지 못하고 천천히 이동할 수 있다. 안정적인 속도·위치 제어는
추후 모터 엔코더를 추가해 외부 속도 제어 루프를 구성해야 한다.
